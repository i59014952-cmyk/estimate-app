# Смета ремонта

Простое веб-приложение для расчёта сметы ремонта.

## Возможности

- Ввод площади помещения
- Раздельные списки работ и материалов (чекбоксы)
- Автоматический расчёт стоимости
- Вывод итога по работам, материалам и общей суммы

## Запуск

Откройте `index.html` в браузере — бэкенд не требуется.

Либо запустите локальный сервер:

```bash
python3 -m http.server 8000
```

И откройте http://localhost:8000

## Стек

- HTML + CSS + ванильный JavaScript
- Без сборки и зависимостей
